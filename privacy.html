Privacy Policy

Channel Uploader is a private tool used only by the owner of one YouTube channel.

With the owner's permission it uses the YouTube Data API to upload videos to the owner's channel, read the channel's own videos and edit their titles, thumbnails and visibility. The access token is stored only on the owner's computer and is not shared with anyone.

The tool does not collect, store, sell or transfer data of any other people. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions.
